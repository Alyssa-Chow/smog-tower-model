Electrostatic Precipitator Smog Tower Model

A Python simulation that models the effectiveness and operating cost of an electrostatic precipitator smog tower for reducing urban air pollution.

What it does:
-Prompts the user for weighted cost and efficiency priorities to determine optimal operating voltage
-Uses Euler's method to numerically estimate particulate matter velocity and position over time under electrostatic force
-Determines whether pollutants are fully filtered based on whether particles reach the collection plate
-Calculates percent change in pollutant concentration and yearly power cost
-Outputs Position vs. Time and Velocity vs. Time plots

Tech stack: Python, NumPy, Matplotlib

I designed and built the full simulation in Python, wrote all code including the physics implementation, Euler's method numerical solver, input validation, cost analysis, and data visualization. Built as part of a team project - the underlying physics calculations and equations were derived collaboratively with the team.
